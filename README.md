دیده بان قیمت ها و اخبار فناوری

سایت نمایش قیمت سکه، طلا، ارز آزاد و ارز دیجیتال به‌همراه اخبار فناوری — ساخته شده با Cloudflare Pages.

امکانات

- 🪙 نمایش قیمت طلا و سکه (طلای ۱۸ و ۲۴ عیار، سکه امامی، بهار آزادی، نیم و ربع سکه)
- 💵 نرخ ارز آزاد بازار (دلار، یورو، پوند، درهم، لیر و ...)
- ₿ قیمت لحظه‌ای ارزهای دیجیتال از CoinGecko API
- 📰 اخبار فناوری از Hacker News API
- 🕐 ساعت و تاریخ شمسی زنده
- 📱 طراحی واکنش‌گرا (Responsive) با پشتیبانی کامل RTL

استقرار روی Cloudflare Pages

npx wrangler pages deploy . --project-name dehdehban-baha
